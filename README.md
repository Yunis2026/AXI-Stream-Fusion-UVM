# AXI-Stream Fusion: UVM Verification Platform

UVM-Based Functional Verification of a Buffered Multi-Beat AXI-Stream Router.

## Project Overview

This project focuses on the RTL design and UVM-based functional verification of a configurable, buffered AXI-Stream router.

## Planned Features

- Multi-beat AXI-Stream packet routing
- Dual-output FIFO buffering
- APB-controlled routing configuration
- Packet-level route locking
- AXI-Stream backpressure handling
- UVM-based verification environment
- Constrained-random verification
- Functional coverage and regression testing

## Technology Stack

- SystemVerilog
- Universal Verification Methodology (UVM)
- Verilator (pending compatibility validation)
- VS Code
- Git / GitHub

## Project Status

Environment setup and RTL development planned.
